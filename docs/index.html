v2s: Live bilingual subtitles, private by design.

v2s turns microphone or app audio into a clean two-line subtitle bar for meetings, calls, streams, and videos. Hear the original language, read the translation, and stay on the window you already use.

How it works

Three steps from download to subtitles.

  1. Install
  2. Configure Choose mic or app audio, set input and subtitle languages, grant permissions once.
  3. Start Click Start in the menu bar — subtitles appear at the top of your screen in real time.

Input and subtitle languages

Language choices matched to your Mac.

v2s asks Apple's Speech and Translation frameworks what your current Mac supports. Available choices vary by macOS version, hardware, and installed or downloadable Apple language models.

Common speech-input examples:

  • Cantonese
  • Chinese (Simplified)
  • Chinese (Traditional)
  • English
  • French
  • German
  • Italian
  • Japanese
  • Korean
  • Portuguese
  • Spanish

Additional subtitle-output examples:

  • Arabic
  • Dutch
  • Hindi
  • Indonesian
  • Russian
  • Thai
  • Turkish
  • Ukrainian

The app shows the exact choices available on your Mac and validates each translation pair before starting. Read the full README →

Privacy

Local-first, with transparent fallbacks.

  • No account, cloud backend, analytics, or telemetry
  • v2s never sends audio or subtitle text to its own servers
  • Translation is on-device; speech uses Apple's service only for languages with no local model
  • Permissions requested only for speech, mic, or app audio capture

open v2s.xcodeproj

First-run permissions

  • Speech Recognition — transcribe audio to text
  • Microphone — when using mic as input
  • Audio Capture — when capturing another app's audio
